# A marble Game
One of my favorite games of all time is Marble Blast Gold, a simple platformer game
in which the player moves around a 3D world as a marble (online port here: https://marbleblast.vaniverse.io/). 
The point of the game is to roll around collecting gems and reaching an end point, 
usually within a time limit. For my capstone project I plan to combine this game's 
control style with the retro graphics of Marble Madness, another marble game. In 
my implementation I plan to render graphics of a marble, platforms, collectibles, 
and checkpoints in a 3D world. I will implement a basic physics system to simulate 
things such as gravity and collisions. There will also be player interaction for 
both moving the marble and the camera. For texturing I will design simple pixel 
graphics for the world and the marble. If I have time for it, I plan to create more
interesting textures/designs, such as reflections or transparency, using cubemaps 
or alpha blending, respectively. I will also try to implement a simple lighting 
system for the world. For the actual gameplay loop in my game, I plan to set up 
a series of checkpoints the marble must touch before reaching a finish line. I hope
for this to be similar to an arcade-style game, where the gameplay is quite linear, 
as it should be easier to build.

I understand that the scope of what I have detailed is quite big from what is suggested. 
However, I really want to apply what I have learned in this class to something that I will 
enjoy and will challenge me. I'm also starting this project quite early (Week 8) because 
I want to see just how much work I will need to put into completing this project and if it's 
too much to have time to pivot to something simpler.
