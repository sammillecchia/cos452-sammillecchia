# A marble Game
One of my favorite games of all time is Marble Blast Gold, a simple platformer game in which you move around a 3D world
as a marble (Online port here: https://marbleblast.vaniverse.io/). The point of the game is to roll around collecting 
gems, and reaching a end point, usually within a time limit. I plan to combine this games control style with the retro
graphics of Marble Madness, another marble game. In my implementation, the plan for the gameplay loop will be a linked 
collection of checkpoints you need to hit before finally having to get to a finish line. I plan to do this since I feel 
it will make the game more similar to an arcade style game, as well as being easier to implement (without needing multiple levels).


I understand that scope of what I have detailed is quite big from what is suggested, however I really want to apply what 
I have learned in this class to something that I will enjoy and will challenge me. I'm also starting this project quite 
early (Week 8) because I want to check out just how much work I will need to put into completing this project, and if It's
too much to have time to pivot to something simpler.
