| **[Week 07](https://sammillecchia.github.io/cos452-sammillecchia/week07/)**<br>Basic camera implementation, renders 2 squares, using the arrow keys pans the camera and +/- zooms | **[Week 07 Stretch Goal](https://sammillecchia.github.io/cos452-sammillecchia/week07/stretch.html)**<br>Draws 2 squares and animates camera panning left and right | |
| **[Week 08](https://sammillecchia.github.io/cos452-sammillecchia/week08/)**<br>Draws 36 vertices and applies matrix transformations to render a rotating cube | **[Week 08 Stretch Goal](https://sammillecchia.github.io/cos452-sammillecchia/week08/stretch.html)**<br>Draws a cube with `CULL_FACE` enabled, increasing performance by skipping rendering of triangles that face away from the camera | |
| **[Week 09](https://sammillecchia.github.io/cos452-sammillecchia/week09/)**<br>Using UVs (texture coordinates) to map a JPG image of clouds to a square | **[Week 09 Stretch Goal](https://sammillecchia.github.io/cos452-sammillecchia/week09/stretch.html)**<br>Mapping UVs onto the cube from Week 08 to draw a brick texture | |

| **[Week 11](https://sammillecchia.github.io/cos452-sammillecchia/week11/)**<br>Implementation of the Blinn-Phong reflection model to simulate glossy specular highlights from a point light | **[Week 11 Stretch Goal](https://sammillecchia.github.io/cos452-sammillecchia/week11/stretch.html)**<br>Using the same model, simulates 3 colored lights (magenta, yellow, and cyan) to create mixed lighting on the surface of the cube | |
| **[Week 13](https://sammillecchia.github.io/cos452-sammillecchia/week13/)**<br>From the Week 08 cube, implements delta time so it rotates at a constant speed independent of refresh rate, with arrow-key interactivity to control the cube | **[Week 13 Stretch Goal](https://sammillecchia.github.io/cos452-sammillecchia/week13/stretch.html)**<br>Uses the Week 11 stretch goal cube and implements zooming with wheel events | |
